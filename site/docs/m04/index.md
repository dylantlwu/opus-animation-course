## 本课目标

- 用**视觉层级**决定每一帧「第一眼看哪、第二眼看哪」
- 建立一套设计 token（色板 ≤4 色及用途、字号阶梯、网格、安全区），写进 `LOOK.md`
- 掌握 2D 动效的「镜头语言」：推拉、平移、匹配剪辑、形变转场、遮罩擦除
- 用**视觉隐喻**把抽象概念变成画面（距离 → 圆，数据流 → 粒子，比较 → 并列）
- 产出：一支片子的 4 张 style frames（静帧）+ 节拍图

## 大纲

1. 构图：三分法、留白、单一焦点、视线引导
2. 视觉层级：大小、对比、颜色、运动——运动永远是最强的层级信号
3. 色彩：主色 / 强调色 / 中性色的比例；颜色随剧情变化（World 一栏）
4. 字体排版：中文字号阶梯、行高、1080p 下 ≥28px、动态字体排版（kinetic typography）
5. 转场语法：硬切、匹配剪辑、形变、推拉、擦除——各自传达什么
6. 视觉隐喻库：科普常用的 20 个「概念 → 画面」映射
7. 反 AI 味：社区点名的俗套与替代方案
8. 实操：让 Opus 出 3 套 style frames，你挑一套并写理由
