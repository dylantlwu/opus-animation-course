# M8 · 动态图形 & Remotion

::: info 🚧 阶段 C 建设中
:::

## 本课目标

- 宣传片结构：痛点 → 产品 → 卖点（3 个以内）→ CTA
- 动态字体排版、UI 动效、「一个形状从不切镜」的形变叙事
- 框架横评：纯 HTML vs **Remotion**（`npx remotion skills add`）vs **HyperFrames** vs Manim——什么时候值得引入框架
- 真实素材：真截图、真 logo、真组件（「永远不要编造一个界面」）
- 产出：一支 15 秒 showreel（但用你自己的简报，不用那句爆款提示词）

## 大纲

1. 宣传片的节奏：0–2 秒强钩子、静止 ≤0.4 秒、结尾 logo 时刻
2. Remotion 入门：`npx create-video`、Studio 预览、`<Sequence>`、官方 skill
3. 许可：Remotion 免费授权的团队规模限制
4. HyperFrames：data 属性 + GSAP 时间线
5. 用代码合成节拍音乐 vs 用授权音乐
