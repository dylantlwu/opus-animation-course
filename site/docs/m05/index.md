# M5 · 导演工作流

::: info 🚧 阶段 B 建设中
:::

## 本课目标

- 把社区共识流水线落成你自己的闸门（G0–G4），并能稳定执行
- 掌握审片工具：`--sheet`、`--strip`、`--still` 局部放大、`--verify`
- 建立**反馈纪律**：每轮只提 1–2 个具体问题，格式「镜头 + 时间 + 问题 + 期望」
- 学会用**新会话严审**和 **HANDOFF.md** 交接长片
- 产出：你自己的 `CLAUDE.md` v2

## 大纲

1. 为什么「一句话出片」不稳定：从 brief contagion 到闸门
2. G1 分镜闸门：多方案、reads、镜头事件检查
3. G2 静帧闸门：contact sheet 自评，打分 ≥8 才过
4. G3 预览闸门：半分辨率、单帧跳变扫描、确定性
5. 反馈纪律与中文改片口令
6. 新会话严审：为什么同一会话会「对自己手软」
7. 长片：分章节文件、HANDOFF.md、subagent 分工（拆参考 / 分镜 / 制作 / 评审）
8. 把每次翻车沉淀成 CLAUDE.md 规则
